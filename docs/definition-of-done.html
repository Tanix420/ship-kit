Definition of Done for AI-written code: make verify.sh the gate

Ask an AI agent "is it done?" and you get a confident paragraph. The problem isn't lying — it's that the agent's definition of done is internal: the code compiles, it looks right, it seems to work. The fix is not a better prompt. It's moving the definition of done outside the agent, into something you both have to look at.

The gate

A single script at the repo root. It runs every check you'd run yourself — syntax, tests, build — and exits non-zero if anything fails. This is the actual one from Ship Kit lite (bash + Node ≥ 18, no npm required):

#!/usr/bin/env bash
# verify.sh — the gate. Not "done" until this exits 0.
set -euo pipefail
cd "$(dirname "$0")"

fail() { echo "VERIFY FAILED: $1" >&2; exit 1; }

command -v node >/dev/null 2>&1 || fail "Node.js not found (need >=18)"
NODE_MAJOR="$(node -p 'process.versions.node.split(".")[0]')"
[ "$NODE_MAJOR" -ge 18 ] || fail "Node.js >=18 required"

echo "[1/3] Syntax check (node --check on all repo JS)..."
while IFS= read -r -d '' f; do
  node --check "$f" || fail "syntax error in $f"
done < <(find . -path ./dist -prune -o -name '*.js' \
  -not -path './node_modules/*' -print0)

echo "[2/3] Tests (node:test)..."
node --test test/ || fail "tests failed"

echo "[3/3] Build (public/ -> dist/)..."
node scripts/build.js || fail "build failed"

echo ""
echo "ALL CHECKS PASSED — verified $(date -u '+%Y-%m-%dT%H:%M:%SZ')"

The two rules that make it bite

  1. Paste, don't summarize. The agent must include the full verify.sh output in its reply. A summary can be invented; a paste with real output and timestamps is evidence.
  2. Two-strikes stop. If the gate fails twice for the same reason, the agent must stop and show you the exact error. This kills the doom-loop where an agent "fixes" the same bug eight ways and then edits the test to go green.

The report prompt

Report: (1) what you changed, (2) which PLAN.md row this maps to,
(3) the final verify.sh output pasted verbatim, (4) anything you did
NOT test, (5) any TODO/FIXME you left and why. If any answer is "none",
say "none" — do not pad.

"Do not pad" matters. Agents pad reports because padding reads as competence. Rewarding "none" over a paragraph of nothing is how you train the loop you actually want: small honest diffs that pass a gate you control.
