Ship Kit AGENTS.md template Stop scope creep Definition of Done

Stop re-explaining your project to your AI agent.

You give the agent a task. It writes code, ignores your conventions, skips tests, wanders off-scope — then tells you it's done. Ship Kit is a repo template that fixes this with one file and one script: an AGENTS.md contract the agent reads first, and a verify.sh gate it can't talk its way past.

Clone the free kit on GitHub MIT licensed. Zero dependencies. Node ≥ 18.

The three failures it fixes

  1. Conventions evaporate. Every new session, you re-explain the stack, the layout, the rules. AGENTS.md makes the rules a file, not a memory.
  2. "Done" is a feeling. The agent says finished; nothing is verified. verify.sh makes done an exit code: syntax check → tests → build, or loud failure.
  3. Scope creep. You ask for a button; you get a redesign. PLAN.md is the scope of record — if it's not in the table, the agent doesn't build it.

What's inside the free kit

  • AGENTS.md — the agent contract: read order, conventions, scope rules, commit discipline, Definition of Done.
  • verify.sh — the gate. Prints ALL CHECKS PASSED or fails loudly. No npm required.
  • PLAN.md — scope of record with a "Proposed" lane for agent ideas.
  • A working zero-dependency demo app — built-in node:test, static server + JSON endpoint + security guard.
  • prompts.md — six copy-paste prompts that enforce the contract.
  • CLAUDE.md — thin pointer so Claude Code picks the contract up natively.

How you use it (10 minutes)

  1. Clone the repo as the starting point of your project.
  2. Run ./verify.sh — see the gate pass before you touch anything.
  3. Open the folder with your AI agent and give it one task from PLAN.md.
  4. Require the verify.sh output pasted in the agent's reply. That's the loop. It never turns off.
